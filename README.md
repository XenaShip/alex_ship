# Ask bot — Telegram-бот для проведения опросов (Django + Aiogram)

**Ask bot** — это система для проведения опросов в Telegram с гибкой настройкой через Django-админку.  
Администратор управляет опросами, вопросами и вариантами ответов через веб-интерфейс, а пользователи проходят опросы в Telegram-боте.

Проект подходит для:
- маркетинговых и исследовательских опросов
- анкетирования клиентов
- сбора обратной связи
- выдачи подарков / материалов после прохождения опроса

---

## 🚀 Основные возможности

### Telegram-бот
- прохождение опросов в удобном диалоге
- поддержка нескольких активных опросов
- повторное прохождение опроса
- разные типы вопросов:
  - **Да / Нет**
  - **Один вариант из нескольких**
  - **Несколько вариантов (мультивыбор)**
  - **Свободный текст**
- поддержка файлов в вопросах:
  - фото
  - видео
  - аудио
  - документы
- выдача подарка после завершения опроса

### Административная панель (Django Admin)
- создание и редактирование опросов
- добавление вопросов прямо внутри опроса
- настройка вариантов ответов (кнопок)
- активация / деактивация опросов
- просмотр клиентов и их ответов
- экспорт ответов в **CSV**
- удобный интерфейс с темой **Jazzmin**

## 🏗 Архитектура проекта

Проект состоит из нескольких частей:

- **Django backend**
  - модели данных (опросы, вопросы, ответы)
  - административная панель
  - работа с базой данных
- **Telegram-бот**
  - реализован на `aiogram`
  - асинхронная логика
  - работа с Django ORM через `sync_to_async`
- **PostgreSQL**
  - хранение данных опросов и ответов
- **Docker Compose**
  - единый запуск всех сервисов

---

## 📊 Модели данных

- **Survey** — опрос (название, описание, активность, приветственный текст)
- **Question** — вопрос опроса (тип, текст, порядок, файл)
- **Mark** — вариант ответа (кнопка)
- **Client** — пользователь Telegram
- **Answer** — ответ пользователя на вопрос
- **SurveyGift** — подарок, выдаваемый после завершения опроса

*** ЗАПУСК ПРОЕКТА (Docker — РЕКОМЕНДУЕМЫЙ способ) ***


1. Клонировать репозиторий
git clone https://github.com/XenaShip/alex_ship.git
cd alex_ship

2. Создать .env
cp .env.example .env


(или создать вручную)

3. Запустить сервисы
docker compose up -d --build

4. Применить миграции
docker compose exec web python manage.py migrate

5. Создать суперпользователя
docker compose exec web python manage.py createsuperuser

6. Открыть админку
http://localhost:8000/admin/

__________________________________________________


*** ЛОКАЛЬНЫЙ ЗАПУСК (без Docker) ***


python -m venv .venv
source .venv/bin/activate  # или .venv\Scripts\activate
pip install -r requirements.txt

python manage.py migrate
python manage.py runserver


В отдельном терминале:

python bot.py

__________________________________


*** РАБОТА С АДМИНКОЙ ***


1. Зайти в /admin

2. Создать опрос

3. Добавить вопросы (inline)

4. Добавить варианты ответов

5. Активировать опрос

6. Пользователи смогут пройти его в Telegram

2. Выбирает опрос
